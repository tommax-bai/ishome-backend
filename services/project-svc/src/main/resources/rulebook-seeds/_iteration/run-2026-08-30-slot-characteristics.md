# 真跑存档 · 2026-08-30 晚 · 在空上给出值的特征：边界说法交还给句子

> 承同日 `run-2026-08-30-wording-around-ref.md` §四立的那条待裁——用户裁决：
> **"在输入的地方给出需要填的值的特征，然后在检测的时候检测内容是否符合这个特征。"**

## 一、裁前的判定材料（十二跑）

原形态是渲染层把边界措辞一起渲出来、写手一律不许写边界词。十二跑证据：

- **边界词违规 9/12 跑**，是这一章过不了检的头号原因；
- 模型自发写边界词共 **17 处，方向 16 处正确**——**能力不是问题**；
- 唯一写错的那处很说明问题：走廊照度在数据里是**确定的 100**（不是门槛），模型写了
  「通行亮度**不能低于** ▢」——它给数据里没有的关系编了一个；
- 根因是**那句中文的语法主干正好落在洞里**：要说一个上界，顺口的说法就是"最多 3 种"，
  而我们要求它写"…种类▢。"。禁词表拦不住（列了四个词，它写了表外的「不能多于」「上限」），
  抽象说"自带边界说法"也拦不住（9/12 复发）。

## 二、裁后的形态

**四种特征，各配一句要求与一道机检**（写作侧与门禁侧共用一份判定，说的和拦的不会是两回事）：

| 这个空是什么 | 记号渲出来 | 句子要怎么写 | 判据 |
|---|---|---|---|
| 固定值 | `3000 K` | 前面不许加边界词 | `gate-bound-word-before-ref` |
| 只给下限 | `90 Ra`（裸值） | 必须写下限那一族的词 | `gate-bound-word-missing` / `-direction` |
| 只给上限 | `3 种`（裸值） | 必须写上限那一族的词 | 同上 |
| 两端齐的区间 | `900–950 mm` | 不许加单侧边界词 | `gate-bound-word-before-ref` |
| 并列多项 | `宽不低于 800 mm、深不低于 800 mm` | 不写——句子够不着每一项 | 同上 |

**分界线只有一条：句子够不够得着。** 一个记号只渲一个值 → 句子在它旁边 → 说法归句子；
一个记号并列多项 → 句子够不着里面每一项 → 说法归渲染层。表格与图框将来同理，那里"旁边"
指列头（触发条件：清单页族落地时同批做那道机检）。

**词表是正面清单**（"必须从这几个词里挑一个"），按词族分方向，正说反说同族（"超过 3 就杂"
也是在说这条上限）。表外的词按"没写"处理并把可用词逐字列出。**失败方向不对称是选它的理由**：
正面清单漏一个词只多烧一轮重写，禁止清单漏一个词缺陷就进成品——今天上午那句叠字正是后者。

**单位不随此变**（另一条裁决未动）：写错单位会改掉这个数的大小，而写错边界词不会；且数据里
的单位是"mm/Ra/×环境照度"这种内部写法，与人话逐字对不上，验不动。

出册那一册读者看到的（逐字）：

> 全屋灯光颜色种类**最多 3 种**。
> 起居灯光显色指数**不低于 90 Ra**，红是红、蓝是蓝、木纹是木纹。
> 起居与主卧的灯光颜色必须统一为 **3000 K**。（固定值，前面无边界词）

对照旧形态同章出的：`全屋灯光颜色种类按 不超过 3 种 做。`——**中文顺了**。

## 四、★ 新立：把一句话的所有权拆开，接缝处会漏

单位违规 0/12 → 2/6，逐字都是 `{lkp-cct-variety-max} 种`。机制不是模型退步，是
**"不超过三种"在中文里是一个词组**：从前它整句都不许写，现在让它写前半（边界词）、
后半（单位）仍归代码，它顺手就把整句写完了。**拆一句话的所有权，接缝就在那儿。**

三条路（未定，待用户裁决）：

- **甲 · 维持**：机检拦得住，代价是 2/6 跑烧一轮重写在这条上；
- **乙 · 单位也交给句子**：渲染层只出数（`3`），单位由写手写、机检**逐字比对登记的展示单位**。
  前置条件是**先登记展示单位**（数据里的 `×环境照度` 对读者要写成「倍」——现在成品里逐字印着
  `亮出 3–5 ×环境照度`，那是内部量纲上了纸）。这样代码只拥有"数"本身，边界最干净；
- **丙 · 反过来收回**：连边界词一起还给渲染层——已被本轮真跑否掉（9/12）。
