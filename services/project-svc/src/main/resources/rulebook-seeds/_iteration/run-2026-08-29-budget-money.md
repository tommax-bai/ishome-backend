## 三、本次采到的样本（真句，未润色）

### A. 造价单元仍未过检 —— 栽的全是 8-28 已登记老形态

终稿（两轮重写后）四条违规，全在 card[0]：

```
gate-number-ref-unresolved  引用 lkp-budget-share-max 不在本域落点对象内
gate-number-ref-unresolved  引用 lkp-budget-share-min 不在本域落点对象内
gate-number-ref-undeclared  占位符未在 number_refs 声明：['lkp-budget-share-max','lkp-budget-share-min']
gate-chinese-numeral        正文以中文数字写数（「近半」）
```

- 一稿把**每一条区间都拆成 min/max**（含五条单价：`{lkp-price-custom-cabinet-min}` 到
  `{lkp-price-custom-cabinet-max}`…）；经门禁反馈，单价那五条改对了，**占比带那条连吃三稿不改**。
- 「近半」与占比带同句共生：`两项叠加后，往往吃掉接近一半的总盘子。`——中文数字纪律与拆区间
  是同一个动作的两面（都想说"这两项占多少"，而落点只给得出区间）。
- **示范句照抄在终稿里消失了**：一稿逐字抄了 persona 示范
  `主材是唯一你能事后调的一项——柜子和水电定了就改不动了。`（8-28 起连续命中），本跑经反馈改掉。
  记此：`gate-sample-verbatim-copy` 的重写循环是有效的，可抄性的代价出在**一稿**，不是出在成品。

### B. 断言预算与新过门的支点脱节 —— 造价章有了钱数，仍然一句判断都不许下

真跑打印：`可作支点的判断句题目: []`，`这轮不许下结论: ['三档差在哪','各分项占比','哪一项决定总价']`。

- 五条单价是本域**唯一**过可核性门（calibrated → THESIS_SUPPORT）的落点；
- 而 `persona-budget` 的三条谓词 `requires` 的全是 draft 参数
  （`lkp-budget-share`/`lkp-budget-driver`/`lkp-budget-tier-gap`），**没有任何谓词用得上单价**；
- 于是 `backed_predicates=[]`：断言预算这一轮又是零。三张卡 `assertions` 全空。

要害：**支点过门了，预算表没跟上**。断言预算是"这轮许说什么"的清单，它按谓词写、按 lkp- 挂；
新过门的落点如果没有谓词挂靠，过门就等于没发生。处置属 persona 改源重编译（规则 4.19），
排在"叙事推导拆两步"那一项里同批做——**本轮不改**：改断言预算等于决定造价章能下什么判断，
要连同"卡片按主张组织"一起想，不能顺手加一条。

### C. 新样本：档位元语言外泄（登记，不入册）

- `bad`：`这些单价落点都可作支点，但它们各自覆盖的工程量需现场确认才能合成金额。`
- `why`：`可作支点` 是 prompt 里给写作器的**档位标签**（规则 4.10a 语域判定的内部说法），
  `落点` 是内部命名空间的概念——两个词都不属于业主语域。同族于 `cr-methodology-language`
  （方法论元语言外泄，规则 4.15），但该判据的词表 `依据|推导|验收标准|本方案|经严谨|综合考量`
  没有这两个词面，机检未触发。
- **不入册**：本轮只有 `bad` 没有逐字可据的 `fixed`（规则 4.18 宁薄勿撑 + §12 禁想象填充）；
  且弱词/元语言词表已裁决**拆两批**处置（词面遗漏补既有判据、语境依赖建新判据），本条属前者，
  等词表批一起补，不占本轮入册名额。
