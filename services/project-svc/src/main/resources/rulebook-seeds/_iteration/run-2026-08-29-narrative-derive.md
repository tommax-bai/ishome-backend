## 二、三跑连败换来的两条实装纪律（都不是模型笨）

1. **推导步没有禁词表 → 写作步兜不住**。第一跑主张里写了 `净宽`，写作器照抄进卡片被
   `gate-banned-term` 打回，重写两轮都在同一个词上死——**下一稿拿到的主张还是那句**。
   处置：禁词下发到推导步 + `parse_claims` 校验命中即打回，理由回流进下一次推导。
   一般化：**产物逐字进下一步 prompt 的环节，必须与下一步同一份口径**（同"prompt 与门禁两处
   口径不一致，写作器会被反复打回却不知道该怎么改"）。
2. **禁词就藏在落点自己的名字里**。真库扫描：`lkp-passage-main` 名叫`主通道净宽`、
   `lkp-passage-secondary` 名叫`次通道净宽`（ergonomics 禁 `净宽`）；lighting 有 **7 条**落点名
   含 `照度`，而该域禁 `照度`。模型每读一次落点清单就在读这个词。
   **处置是改说法不改数据**：`照度` 在落点名里是准确的，逼它改成业主词面会把「照度」写成「亮度」，
   那是两个物理量——语域分界在**正文**，不在内部标签。两步 prompt 都明说了"名字是内部标签"。

## 三、本跑新采到的三条（登记，未处置）

1. **主旨句逐字等于主张**（5/5）。形态与"正文逐字等于主旨句"同构，只是抄的对象换成了上一步的
   产物：写作步没有做语域转换。当前无害（主张已被禁词门禁逼成人话），但**推导是内部语域**这条
   设计口径在事实上没有兑现。要不要加护栏（`thesis != claim`）留给下一轮——先看它是不是常态。
2. **判官把"按主张归组"读成射程外推**。5 张卡 **5/5** 命中 `cr-anchor-out-of-scope`，理由逐字：
   > `该句将 lkp-wall-cabinet-bottom 与 lkp-sink-depth 绑定为'互相让'关系，但二者在落点定义中无交互参数`

   即：**新设计要求把落点归组讲，判官把归组本身判成违规**。这与上一轮登记的"疑过拦"是同一条
   判据、同一个方向，现在有了机理：它的立案样本是"用起居照度背书走廊"（越到**其他空间**），
   而现在命中的是"把两条同族落点放进一句因果"。观察态不拦截故当前无损，但**若此刻转正，每张卡
   都会被拦**。处置需要裁决（收窄 requirement 还是禁止跨落点因果），不在本轮。
3. **budget 仍未过检**（5 条主张 → 5 张卡 → 5 条违规）。栽的是老形态：`gate-lkp-identifier-leak`、
   禁词`可能`/`推导`、`cr-weak-word`、`cr-methodology-language`——**全部集中在最后两张卡**，
   而那两张对应的正是**没有背书的题目**（各分项占比 / 哪一项决定总价）。真句：
   > `各分项在总造价中的相对权重无法锚定于固定比例，因为拆除量直接挤压定制柜投影面积的可布设范围…`

   没东西可说时，模型用元语言和伪因果填。**伪因果（⑧）已在挂账清单里**，本跑给它添了一条真样本。

## 四、persona 改源同批（详见 backend `7a90092`）

- **断言预算接上单价支点**：新增谓词`各工项单价行情`，requires 五条 `lkp-price-*`（造价域唯一
  calibrated 的落点）。射程收死：不背书总价（量还没有）、不背书占比、不跨口径比较单价高低。
- **六域示范改源**：✗ 不再演示机检判得出的那一半（裸数字/禁词），✓ 不写成能独立成立的结论句
  （拴在 `{lkp-*}` 或以"它/这一项"起头）。两侧对称过滤后 **19 对全部可下发（改源前 4 对）**。
  **可抄性是否真的解掉要看后续真跑**——A/B 量到的是"示范越多过检率越低"，而示范总量刚从 4 涨到 19。
- 同批删掉三处 persona 自己教编造的示范（`你说过不想天天擦` / `主卧窗朝东` / `你选的那个米色`），
  与 8-28 `persona-ergonomics` 教模型编造家庭成员同源。
- **ergonomics 的 `assertions` 仍是 0/5**：该域 0 条 calibrated 落点，断言预算三条谓词全无背书——
  这是**正确行为**不是缺陷。造价域的验证要等 budget 过检。

## 五、结论

"一数一卡"这个形态被修好了：卡片数由主张定、每张卡带 2~3 条落点、正文不再是主旨句的复读。
