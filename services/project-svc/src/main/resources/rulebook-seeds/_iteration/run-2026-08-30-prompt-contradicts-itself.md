# 真跑存档 · 2026-08-30 深夜 · prompt 自己在写它禁的词 + 打回带历史

> 用户裁决三条：**"如果不能过，那我们就看它如何能过不就好了吗？"**（不为测量而测量）；
> **"改说叉叉叉……不是裁判模型应该做的事情"**（判据只判不写）；
> **"将上一轮、上上轮、上上上轮三次被打回的原因都给到模型"**（打回带历史）。

## 一、被问住的那个问题

上一批六跑失败的两跑，形态一模一样：**同一个禁词连写三稿**（一跑「照度」、一跑「宜」），
打回两轮一个字没改。用户直接问：**为什么会写禁词？是不是 prompt 写得不够简单清晰？**

查下来不是"不够清晰"，是**自相矛盾**加**该装的没装**。

## 二、三个查实的事实

**① 我们让它别写的词，是输入里出现最多的词。**
灯光域 13 条落点，**7 条题名带「照度」**（卫生间照度标准值、卧室照度标准值……），逐行递进 prompt；
纪律条文举例又写一次；禁词表本身再写一次。模型全篇看见「照度」**9 次，其中 8 次是我们递的**，
然后被要求"一个都不能出现"。「依据」同理：写作 prompt 4 次、推导 prompt 3 次，而它本身在公共禁词表内。

**最直接的一处**：纪律第 6 条原文是"落点的名字里**可能**就带着禁词（如「**照度**标准值」）"
——**一句话踩两个禁词**。

**② 治它的办法早就写好了，但没装在出文那一步。**
2026-08-29 立过"撞禁词的落点**逐行点名**"（数据驱动 banned ∩ name），证据是全局提醒压不过逐行复现
（「净宽」连吃三稿）。但它**只装在推导步**。正文是写作步写出来的，禁词也是在那儿进正文的——漏装。

**③ 一张 25 词的表混了四类毛病，打回话只有一句。**
行话（照度/显指/光通量/眩光值）、虚词（可能/也许/宜/尽量）、免责措辞（保证/承诺/责任/无风险）、
元语言（依据/推导/本方案）。"换人话说"对行话成立，对虚词不成立——「可能」换成「或许」还是禁词。
**上一批 v5 就是证据**：同一个「宜」，禁词判据与弱词判据一起中，说明它不是选词问题，
是那句话不该用不确定语气。这一类的分表处置**留作下一件**，本轮未动。

**落点名不改**（坑单四已裁：「照度」在题名里准确，改「亮度」是另一个物理量），
**改的是 prompt 自己的措辞**：依据→背书／理由，举例整句撤掉，逐行点名补到写作步。

## 三、判据不给替代说法（用户当场驳回的一个提法）

当时提的改法是给禁词表每条加"替代说法"字段，打回话从「禁词『照度』→ 换人话说」变成「→ 改说『××』」。
用户驳回，理由是**那不是裁判该做的事**。落档时补的第二条连带理由：**替代说法固定在 release 数据里，
每份报告都说同一个词＝人预设模板**，撞 AI native 红线。
现形态：打回只说"这个词不行"，换成什么由写手自己判断；**它判不出来时的后续路径写死＝
把它已经试过的写法告诉它**（下一节），不是给它答案。

## 四、打回带历史（本轮第二件）

**上一批失败的共同形态是"同一条错连吃三稿"**，成因是模型每轮只看得见"这一稿哪儿错"，
看不见"上一轮我也是这么写的"。现形态三条：

1. 最新一稿**带全文**（8-30 早先裁决"重写要看得见上一稿"）；
2. 更早各轮**只带打回原因不带原稿**——原稿摆在眼前会把改动退化成在旧句子上挪字，
   被打回的词反复进 prompt 也容易把它钉死在那个词上；
3. 同一条判据跨轮再犯的**直接标在当条违规后面**（"第 1、2 稿也栽在这条"），
   **按判据归并不按卡片归并**：卡片序号每轮会变，判据 id 不变，措辞挪到另一张卡不算改掉。

**推导步同病同治**：它此前只拿到一句错误文字、稿子本身不回传——与写作步早先修掉的是同一个毛病，
只是漏在了这一步（用户裁决射程写明是"所有裁判场"）。本轮补齐：异常带回被打回的那组主张，
更早各轮只带理由，重复犯的标出来。

## 五、推导步补第五道确定性校验

推导步已有四道（耦合措辞、禁词、条目照抄、项名），**独独没有数字那道**——而"不许出现任何数字"
正是它自己的纪律第 2 条，也是全项目最要紧的红线。真跑立案：主张写"暖冷调子加起来不能超过三种"，
逐字进写作 prompt，写作步照抄后被 `gate-chinese-numeral` 打回，重写两轮拿到的主张还是那句。
**与写作步同一份正则**（同一份口径）：列举计数不在射程（"四个区域"不算数）。

## 六、长效拦法：两步各一条守卫测试

把禁词表本身那一处剔除后，prompt 里再出现任何禁词即测试失败——写作步、推导步各一条。
**与铁律一不冲突**：题名撞词的逐行点名不是把新词面塞进 prompt，
是给一个已经不得不出现在输入里的词贴内部标签。

另加一条**档名一致性**守卫：纪律引用的档名必须是落点行真的印出来的那几个字。
立案：原文写"标【未过门·建议口吻】的照常用"，而落点行印的是「没有外部背书，用「我们建议…」的口吻」
——纪律指着一个 prompt 里不存在的标签。与①同族：**指令与它所描述的输入对不上，模型只能猜**。
