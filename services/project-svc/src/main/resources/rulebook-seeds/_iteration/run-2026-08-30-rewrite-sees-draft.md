## 一、改前是什么样（这是个洞，不是调参）

重写时递给写作器的是：这一章要讲的几件事（不变）、落点清单、**一张违规清单**。
**上一稿的卡片没有回传。**

即：我们让它"逐条修正"一份**它已经看不见的稿子**。它实际做的是从头再写一章，只是被告知上次
踩了哪些坑。真跑症状全对得上——违规在卡片之间跳（这一轮 card[3]、下一轮 card[4]）、同一条错
两轮都在、最后一轮才冒出全新的错。代码与文档里都没有"故意不给"的理由。

## 二、改后

1. **上一稿原样带回**，违规按 `card[i]` **归位挂到那张卡下面**，整稿级的单列在最前，
   并明说"**没被点到的卡片原样抄回**（改动越少越好）"。模型看到的是"这一张的这一句要改"，
   不再是"重写一章并避开这些坑"。
2. **打回三件按序写死**：`「原文片段」+ 哪儿不对 + → 怎么改`，且短。
   - 规则层逐条改写，最长一条从 150 字压到 30 字上下（原来 120 字在解释这条纪律为什么存在——
     那些字逐字进下一稿的 prompt，在那里只是噪音）；
   - **`cr-` 判据补上原文**：它的 message 是 release 数据、只说"哪儿不对"，
     像 `cr-weak-word` 只说"分析级结论句禁弱词"，模型根本不知道是哪个词；
   - 候选词只给最顺的三个（机检仍认全表）——打回要短，选择摊开反而慢；
   - 判官层本就是 `判官命中「原句」：为什么`，形态已合，未动。
