## 判定：路走得通，但有四个如实记录

1. **公开行情的"两源一致"是宽松一致**——区间互相重叠但边界不同（点位 150-300 vs 200-500）。处理：取并集 + 置信 low + 区间放宽（lkp-budget-confidence-width）。严格一致只在国标类数据上成立（照度两版同值）。
2. **口径问题比数字问题大**：拆除有"纯拆"与"打包"两种口径；定制柜有投影/展开/延米三种计价；乳胶漆疑似只含人工。写回时一律记源生口径、不做换算推导（定制柜单位已从"延米"改为"投影㎡"）。
3. **城市档没取到**——全部只有全国粗档。城市分档需要各地信息价类数据源，本轮公开行情文章给不了。
4. **本轮全部仍为 draft**：核验跑批（规则 4.10a 四项）还没建，source 已可定位只是转 calibrated 的前提，不是充分条件。跑批随灌库脚本落地（任务序列第 3 项）。
